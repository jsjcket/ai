# 金融理财智能助手

一个专为理财小白设计的金融理财助手，帮助你分析市场、筛选基金、计算定投、监控风险。

## 功能模块

### 1. 市场行情分析
- 获取A股/美股实时行情
- 生成市场分析报告
- 大跌预警提醒

### 2. 基金筛选配置
- 根据风险偏好推荐配置
- 基金筛选条件生成
- 支付宝操作指导

### 3. 定投计算器
- 定投收益计算
- 定投计划生成
- 止盈策略分析

### 4. 风险预警
- 市场风险等级评估
- 持仓风险报告
- 预警设置

## 项目结构

```
ai/
```

## 快速开始

### 在Trae中使用

直接在对话框中提问：
- "查询今日股市行情"
- "我有10000元，稳健型，帮我推荐基金配置"
- "每月定投1000元，定投3年，年化收益8%，计算收益"
- "今天大盘跌了3%，风险等级如何？"

### 运行Python代码

```bash
cd d:\杂物\ai
python finance_assistant.py
```
